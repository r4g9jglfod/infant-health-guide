# 【节气养生】冬至，温补防寒~“阳过”&“阳康”人群调养身心关键时节

> 更新时间：2026-09-16 (UTC+8)

冬至是一年之中阴气最为旺盛的一天，从这之后一阳始生，阳气产生并逐渐旺盛。一年中最冷的“三九天”也将在冬至日后拉开帷幕。冬至保健养生尤为重要，健康过冬也为来年做好“能量”储备。**阳性感染者及康复后的人群抓住冬至这个契机，调养身心，顺时而为也尤为重要。**

**0****1**

**敛阴气、重保暖**
**生活起居养生方面**，作息宜早卧晚起，等待阳光出现后再出来活动为宜。冬至时节前后睡好午觉也尤为重要。睡眠安则阴气敛，阴精盛，继而“一阳”得以生升。在冬至前后，还要特别注意避寒就温。在穿好保暖衣物以抵御寒气侵袭的同时，要特别注重双足的保暖。暖双足则可防体寒：要穿着保暖的鞋袜，坚持热水泡脚、或者可用艾叶、花椒、生姜煮水泡脚以温通足底经脉。常按摩足底的涌泉穴，可以温肾助阳，散寒湿之邪。

阳性感染者更要注意保持充足的睡眠，保暖御寒。值得注意的是，“阳康”群体在身体逐渐康复后不要急于做剧烈的运动，应以节奏柔缓的运动为宜，可以选择中医导引术，比如八段锦、五禽戏等能够疏通经络、改善身体素质并增强抗病能力。
**0****2**

**适当进补**
冬至时节，**饮食摄入**要注重谷、肉、果、菜、多种食物的合理搭配。在进补之时，当辨证施补，虽说冬日注重养阳，可适当进食羊肉、枸杞、韭菜等温热之品，但对于本就湿热蕴滞脾胃之人不可多食。大白菜、山药、萝卜等都是适合冬至养生之品，大白菜是富含水分、维生素 C和维生素E, 既能养颜护肤又能润肠排毒，促进胃肠蠕动。

阳性感染者及“阳康”群体更要注意，不可过度滋补，饮食宜清淡为主，每日三餐规律进食，保证食物多样，并可适当多食用一些顾护脾胃，清肺益气的食物，比如山药、白扁豆、大枣、木耳、百合雪梨羹等。
**0****3**

**疾病预防，安全过冬**冬至天气寒冷，昼夜温差大，是很多疾病的高发时节，比如心脑血管疾病、呼吸道疾病包括现在正在流行的新冠肺炎等。预防心脑血管疾病，尤其要警惕血压波动，血压过高容易增加心脑负担。因此，要坚持定期测量血压，生活起居上注意保暖，劳逸结合，避免情绪波动，饮食要清淡少盐，多吃蔬果，保持大便通畅。预防呼吸道疾病，要注意室内适当通风并保持一定的湿度。尤其是阳性感染者居家一定要注意**每天开窗通风30min以上**，以此可以有效降低空气中的病毒浓度。另外，我们也可以巧妙利用身体的腧穴，通过推拿、点按的方法减缓新冠肺炎症状，增加机体抗病能力。比如，**鼻塞患者**可坚持每天早晚揉按鼻翼旁的迎香穴，以达通鼻利窍之功；**头痛患者**可双手轻轻按揉风池穴1-2分钟，祛风散寒，缓解新冠肺炎引起的头痛、后项痛的症状；揉按或拔罐于大椎穴，有清热解表之效。
